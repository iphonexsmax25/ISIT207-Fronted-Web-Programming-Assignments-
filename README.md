# 🌐 ISIT207 Frontend Web Programming - Assignments

Welcome! This repository contains assignment solutions and reference code for **ISIT207 Frontend Web Programming**. 

It serves as a personal backup and an open reference resource for juniors and peers looking to learn, review structure, or cross-check solutions.

---

## 📌 Repository Structure

Each assignment is organized in its own **git branch** to keep the workspace clean and easy to navigate.

### How to Switch Branches:
1. Locate the **branch dropdown menu** at the top-left of the main repository page (defaults to `main`).
2. Select the assignment you wish to view:
   * `Assignment-1` → Solution & resources for Assignment 1
   * `Assignment-2` → Solution & resources for Assignment 2
   * `Assignment-3` → Solution & resources for Assignment 3
   *(and subsequent assignments)*

## 🛠️ Getting Started & How to Run

## 🛠️ How to Run the Project (VS Code Step-by-Step)

Follow these simple steps to open and view any assignment in **Visual Studio Code**:

### Step 1: Download or Clone the Repository
* **Method 1 (Git Command):**
  1. Open your terminal or command prompt.
  2. Run:
     ```bash
     git clone [https://github.com/iphonexsmax25/ISIT207-Fronted-Web-Programming-Assignments-.git](https://github.com/iphonexsmax25/ISIT207-Fronted-Web-Programming-Assignments-.git)
     ```
* **Method 2 (ZIP Download):**
  1. Click the green **Code** button at the top right of this repository page.
  2. Click **Download ZIP**.
  3. Extract (unzip) the downloaded folder on your computer.

---

### Step 2: Open the Folder in VS Code
1. Launch **Visual Studio Code**.
2. Go to the top menu and click **File $\rightarrow$ Open Folder...** (or press `Ctrl + O` on Windows / `Cmd + O` on Mac).
3. Select the unzipped repository folder and click **Select Folder**.

---

### Step 3: Switch to the Desired Assignment Branch (if using Git)
If you cloned the repo using Git, switch branches to see different assignments:
1. Look at the **bottom-left corner** of the VS Code window (on the status bar).
2. Click on the branch name (e.g., `main`).
3. Select the assignment branch you want to view from the top dropdown list (e.g., `Assignment-1`).

---

### Step 4: Open and Run in Browser
1. In the VS Code **Explorer** panel on the left sidebar, click on the assignment folder you want to view.
2. Right-click on the `index.html` file.
3. Select **Reveal in File Explorer** (Windows) or **Reveal in Finder** (Mac).
4. Double-click `index.html` to open and view the webpage directly in your web browser.
